\# 麻将小程序项目

> 基于微信小程序的麻将游戏



\## 项目简介

本项目是一款麻将微信小程序，实现基础麻将对局能力，支持碰、杠、胡等核心麻将玩法，可在此基础上扩展房间、联机、AI、计分、自定义规则等功能。



\## 技术栈

\- 框架：微信小程序原生 / uni-app / Taro（自行修改）

\- 语言：JavaScript / TypeScript

\- 后端（可选）：Node.js / Java / Go

\- 其他：WebSocket（联机对战）



\## 目录结构（示例）

```

├── pages                # 页面

│   ├── index            # 首页

│   ├── room             # 房间页

│   ├── game             # 麻将对局页

│   └── result           # 结算页

├── components           # 自定义组件（麻将牌、牌桌等）

├── utils                # 工具函数

│   ├── mahjong.js       # 麻将核心逻辑：发牌、判胡、碰杠检测

│   └── common.js        # 通用方法

├── store                # 状态管理（可选）

├── static               # 静态资源：图片、音效

├── app.js

├── app.json

├── app.wxss

└── project.config.json  # 小程序配置

```



\## 快速启动

1\. 安装 \[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

2\. 克隆代码仓库

```bash

git clone xxx.git

cd xxx

```

3\. 使用微信开发者工具导入项目，选择项目根目录

4\. 修改 `project.config.json` 中的 `appid` 为你自己的小程序 AppID

5\. 编译运行，在模拟器/真机预览



> 如果是 Taro / uni-app 项目，替换成对应的 npm 启动命令



\## 麻将核心能力（当前规划）

\- ✅ 牌库初始化、洗牌、发牌

\- ✅ 摸牌、弃牌

\- ✅ 碰、杠（明杠、暗杠）

\- ✅ 胡牌判定

\- ⏳ 多人联机（WebSocket）

\- ⏳ 计分、番型结算

\- ⏳ 房间创建、邀请好友

\- ⏳ AI 机器人

\## 开发规范

1\. 麻将核心算法尽量抽离到 `utils/mahjong.js`，和视图层解耦

2\. 变量命名语义化，注释关键算法（胡牌逻辑容易踩坑）

3\. 提交规范：

&#x20;   - feat: 新增功能

&#x20;   - fix: 修复bug

&#x20;   - refactor: 重构

&#x20;   - docs: 文档修改

&#x20;   - style: 样式调整



\## 注意事项

1\. \*\*合规重点\*\*：微信小程序严禁赌博相关，本项目仅做休闲娱乐，\*\*不能接入充值、现金结算\*\*，上线前务必遵守微信小程序规范和法律法规；

2\. 音效、图片资源注意版权；

3\. 联机版本需要自己部署 WebSocket 服务；

4\. 不同地区麻将规则不一样（川麻、广东麻将、推倒胡等），胡牌、番数逻辑需要单独适配。
